# Local font files

Run npm run fonts from the project root. It fetches the three WOFF2 files used by next/font/local:

- clash-display.woff2 — Clash Display variable, Fontshare
- satoshi.woff2 — Satoshi variable, Fontshare
- jetbrains-mono.woff2 — JetBrains Mono regular, SIL Open Font License

The script skips existing files. If network downloads are blocked, obtain the fonts from their original publishers and place them here using these exact filenames. Do not substitute unrelated font binaries under these names.
